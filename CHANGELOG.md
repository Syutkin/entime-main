# Changelog

## [0.8.0] - 2025-07-25

### Changed

- Максимальное количество СУ увеличено до восьми.

## [0.7.24] - 2025-06-27

### Changed

- Некоторые пункты контекстного меню отключены в режиме гонки.

## [0.7.23] - 2025-06-26

### Added

- Проверка обновлений через интернет.
- Автоматическое создание резервных копий соревнования по таймеру.

### Fixed

- Исправлена отправка имён участников в Telegram-бот.

## [0.7.22] - 2025-06-24

### Changed

- Удалены неиспользуемые разделы меню «Файл».
- Окно с отладочной информацией по умолчанию отключено.

### Fixed

- Исправлены ошибки при импорте результатов.
- Исправлены ошибки при экспорте результатов отдельного СУ.
- Таблица поправок корректно обновляется после изменения поправки в основной
  таблице.

## [0.7.21] - 2025-06-23

### Fixed

- Исправлена ошибка доступа к базе данных после записи отсечки времени.

## [0.7.20] - 2025-06-23

### Added

- Переключатель автоматического обновления результатов при ручном изменении
  времени старта, времени финиша, поправки или штрафа.
- Переключение языка без перезапуска приложения.
- Сортировка, скрытие и перемещение столбцов в основной таблице.

### Changed

- Обновлён английский перевод.
- К сочетаниям клавиш добавлен модификатор Shift.

### Fixed

- Исправлены ошибки интерфейса.
- Исправлены прочие обнаруженные ошибки.

## [0.7.19] - 2025-05-17

### Changed

- Формирование стартового протокола перенесено в меню «Соревнование».
- При формировании стартового протокола необходимо выбрать СУ.
- Режим «По текущим результатам» использует результаты всех активных СУ.
- Результаты квалификации можно исключить из финального протокола, отключив
  соответствующий СУ после формирования стартов.

## [0.7.18] - 2025-05-14

### Added

- Экспорт результатов в CSV для формирования общего рейтинга серии
  соревнований.
- Название соревнования в настройках.
- Имена файлов по умолчанию для операций экспорта.

### Changed

- Улучшен экспорт отдельных этапов в CSV.
- Настройки формирования стартового протокола сохраняются для последующего
  использования.
- Выполнены прочие небольшие улучшения.

## [0.7.17] - 2025-05-04

### Added

- Загрузка имён СУ из стартового протокола.

### Changed

- Улучшен экспорт финишного протокола.

## [0.7.16] - 2025-04-24

### Added

- Экспорт стартового протокола в CSV.
- Поля телефона, электронной почты и комментария в основной таблице.

## [0.7.14] - 2025-01-25

### Added

- Поддержка Windows-кодировок.
- Примеры импортируемых файлов в каталоге `samples`.

## [0.7.13] - 2025-01-11

### Added

- Импорт стартового списка из CSV.
- Обязательные поля номера, имени и хотя бы одного стартового времени.
- Поддержка необязательных полей категории, ника, года рождения, команды,
  города, телефона, электронной почты и комментария.
- Независимый от порядка и регистра разбор заголовков.
- Использование произвольных названий СУ в столбцах стартового времени.
- Поддержка стартовых списков в CP1251 для Windows и UTF-8 для Linux.

## [0.7.0] - 2019-07-10

### Added

- Назначение номера при добавлении нового участника.
- Сохранение места в общем протоколе в базе данных.
- Настройки COM-порта в окне настроек.
- Выбор категории из выпадающего списка в основной таблице.
- Окно «О программе».
- Окно настроек.

### Changed

- Обновлено оформление вкладки «Статистика»: добавлены автоматические размеры
  и прокрутка.
- Наименования на вкладке «Результаты» зависят от количества СУ.
- Улучшен диалог экспорта результатов.
- Количество этапов используется вместо фиксированного числового значения.
- Открытие базы данных вынесено в отдельную процедуру.
- Добавлена обработка исключений при работе с базой данных.
- Изменена проверка наличия базы данных.
- Отладочная информация удалена из релизного интерфейса.

### Fixed

- Настройки соревнования не загружались при открытии базы данных.
- Изменения не сохранялись при открытии базы данных.
- Исправлена компоновка интерфейса при изменении размера окна.
