# Entime

Entime — настольное приложение для хронометража спортивных соревнований,
ведения участников и расчёта результатов на нескольких специальных участках
(СУ).

[Скачать последнюю версию](https://codeberg.org/Syutkin/entime/releases/latest)

## Возможности

- ведение списка участников и их стартового времени;
- импорт участников и результатов из CSV;
- работа с соревнованиями, включающими от 1 до 32 СУ;
- формирование стартовых, финишных, суммарных и сквозных протоколов;
- приём отсечек времени через последовательный порт и Bluetooth Low Energy;
- ручное сопоставление и корректировка стартовых и финишных отсечек;
- автоматический пересчёт мест и отставаний;
- экспорт результатов в CSV и электронные таблицы;
- отправка результатов в Telegram и на светодиодную панель;
- автоматические и страховочные резервные копии базы данных;
- журналирование действий приложения;
- русский и английский интерфейс с переключением языка без перезапуска.

## Установка и запуск

Entime выпускается для Windows и Linux x86-64.

1. Скачайте архив для своей операционной системы со страницы
   [релизов](https://codeberg.org/Syutkin/entime/releases).
2. Распакуйте архив в отдельную папку. Не запускайте программу непосредственно
   из архива.
3. В Windows запустите `Entime.exe`, в Linux — `entime`.

В Linux при необходимости разрешите запуск файла:

```bash
chmod +x entime
```

Не переносите исполняемый файл отдельно от остальных файлов архива: каталог
`languages` и поставляемые библиотеки должны находиться рядом с программой.

## Быстрый старт

1. Выберите **Файл → Новое соревнование** и сохраните файл соревнования в
   удобном месте. Существующее соревнование можно открыть через
   **Файл → Открыть**.
2. В разделе **Соревнование → Параметры соревнования** укажите название,
   количество и параметры СУ.
3. Добавьте участников вручную в главной таблице или загрузите подготовленный
   список через **Файл → Открыть список участников**.
4. Откройте **Инструменты → Настройки** и выберите источник отсечек времени:
   последовательный порт или BLE.
5. При необходимости сформируйте стартовое время командой
   **Соревнование → Сформировать стартовый протокол**.
6. Во время соревнования контролируйте входящие стартовые и финишные отметки,
   сопоставляйте их с участниками и исправляйте спорные значения.
7. После завершения проверьте результаты и выберите
   **Файл → Экспорт финишного протокола**. Протокол можно сохранить в формате
   XLSX или ODS; дополнительные виды экспорта доступны в том же меню.

Все изменения сохраняются в файле текущего соревнования с расширением
`.sqlite` или `.db`.

## Подключение устройства хронометража

В разделе **Инструменты → Настройки** выберите режим входа:

- **Serial (COM-порт)** — укажите порт и параметры соединения, затем выполните
  **Инструменты → Открыть COM порт**;
- **BLE** — выберите доступное устройство хронометража в настройках BLE.

Если нужного устройства нет в списке, проверьте, что оно включено и не занято
другой программой. В Linux пользователю также может потребоваться разрешение
на работу с последовательными портами и Bluetooth.

## Список участников в CSV

Entime принимает CSV-файлы с разделителем `;`. Первая непустая строка должна
содержать названия столбцов. Столбец с номером участника обязателен. Известные
названия полей распознаются как данные участника, а остальные — как названия
СУ.

Пример:

```csv
Номер;Имя;Категория;СУ 1;СУ 2
1;Иван Иванов;М21;10:00:00;11:15:00
2;Пётр Петров;М21;10:01:00;11:16:00
```

Поддерживаются, в частности, поля имени, категории, команды, города, года
рождения, телефона, электронной почты и комментария. Порядок столбцов и
регистр их названий значения не имеют. Допустимы файлы UTF-8 и распространённые
Windows-кодировки.

## Данные и резервные копии

Каждое соревнование хранится в отдельном файле. Чтобы перенести соревнование
на другой компьютер, достаточно скопировать его файл `.sqlite` или `.db`.

Entime создаёт автоматические и страховочные резервные копии. Их параметры
можно изменить в настройках. Не редактируйте файл соревнования другими
программами, пока он открыт в Entime.

## Язык интерфейса

Язык выбирается через **Инструменты → Настройки → Язык**. Изменение применяется
без перезапуска программы.

## Обновления и диагностика

Проверить новую версию вручную можно через
**Помощь → Проверить обновления**. Список изменений опубликован в
[`CHANGELOG.md`](CHANGELOG.md).

Если возникла ошибка, откройте журнал через
**Инструменты → Журнал → Открыть текущий файл**. Сообщить о проблеме можно в
[трекере Codeberg](https://codeberg.org/Syutkin/entime/issues), приложив
описание действий, версию Entime и соответствующий фрагмент журнала. Перед
публикацией убедитесь, что журнал не содержит чувствительных данных.
